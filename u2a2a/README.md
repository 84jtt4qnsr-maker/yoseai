# U2A2A Orchestration

Canvas「U2A2A app イメージ」を実装したローカルアプリ。
ユーザー ⇄ Claude Code ⇄ Codex の三者テキストオーケストレーション＋タスクキュー。

## 起動

```bash
node u2a2a/server.mjs
```

→ http://127.0.0.1:4742 （ポートは環境変数 `U2A2A_PORT` で変更可）

依存パッケージなし（Node 標準ライブラリのみ）。

## 使い方（Canvas の流れそのまま)

1. **ユーザー帯（上段・緑）** — Claude Code / Codex / 両方 のスレッドへ発言（回答・質問）。
2. **Claude Code 側スレッド（左・橙）／ Codex 側スレッド（右・水色）** — 各アプリでのエージェントの返答・質問を貼り付けて記録。
   - メッセージの「○○へ転送」で A2A（エージェント間）中継。
3. **タスク化** — やり取りから生じたタスクをメッセージからワンクリックでキューへ。
   - 「プロンプトをコピー」で Claude Code アプリ / Codex アプリに貼って作業。
   - 状態: キュー → 作業中 → 結果あり → 完了。
4. **結果を入力** — 各アプリでの作業結果を貼ると、担当エージェントの発言としてスレッドへ再入力される。

## CLI 自動応答

`claude` / `codex` CLI が入っていれば、各スレッドへの発言に対してエージェントが自動で返答する
（スレッドヘッダの「自動応答」でON/OFF、OFF時は従来どおり貼り付け運用）。

- Claude: `claude -p --resume <session>` — 要 `claude` → `/login`
- Codex: `codex exec` / `codex exec resume <session>` — 要 `codex login`
- どちらも読み取り専用（実装作業はさせない。作業はタスクキュー経由で各アプリにて）
- セッション ID を保存してスレッドの文脈を継続。エラーはヘッダに赤字表示（ホバーで詳細）

## レイアウト

- 右半分: 共有タスクプール — Finder 風ファイルブラウザ（左: ツリー＋検索、右: 選択ファイルの詳細・レビュー）。
  「折りたたむ」でファイルリストだけのレールに収納（行クリックで自動展開＋選択）
  - サブフォルダ対応（▸/▾で開閉）。フォルダをクリックすると「作成先」に指定される
  - ツールバーの 📁+ / 📄+ で新規フォルダ・新規ファイルをその場で作成（ターミナル不要）
  - 持ち込みダイアログ（テキスト/アップロード）も作成先フォルダに保存される
  - 検索中はツリーをフラット化してパス付きで横断表示
- 左半分: ユーザー帯・Claude/Codex スレッド・タスクキュー（未完了があるときだけ自動展開）
- メッセージの操作ボタンはホバーで右上に表示
- 幅 1100px 未満のウィンドウでは自動的に上下配置（プールが下段）に切り替わる

## 表示

メッセージ本文は Markdown をレンダリング表示する（見出し・リスト・コードブロック・
インラインコード・表・引用・太字/斜体/打ち消し・リンク）。内蔵の軽量レンダラーで
外部依存なし、HTML タグはすべてエスケープされるため安全。
メッセージごとの「生表示」ボタンで元テキストと切り替え可能。

## 質疑モード（エージェント間の自動質疑応答）

送信先で「🗨 質疑（Claude先手／Codex先手）」を選んで発言すると、
先手エージェントの**応答完了を待ってから**相手スレッドへ自動中継し、交互に質疑が進む。

- 上限手数（既定6、送信時に変更可）に達すると自動停止
- エージェントが応答末尾に「【質疑終了】」と書くと合意成立として早期終了
  （ただし相手が一度も発言していない段階の終了宣言は無効 — 最低1往復を保証）
- 進行中は上部バーに残り手数を表示、「質疑を停止」でいつでも中断
- CLI エラー時は安全のため自動停止

## 共有タスクプール（成果物置き場 = アプリ専用 DAS）

実体は **`u2a2a/pool/` フォルダ**（git 管理外）。全アイテムが実ファイルで、
エージェント CLI からは `u2a2a/pool/<name>` のパスでそのまま読める。

- 持ち込み方法:
  - メッセージ／タスク結果の「プールへ」、「＋持ち込み」のテキスト入力（`.md` として保存）
  - 「＋持ち込み」のファイル添付（アップロード）
  - **`u2a2a/pool/` にファイルを置くだけ**（Finder でも、エージェントが自分の CLI セッションから
    書き込んでも、20 秒ごとのスキャンで自動登録される）
- 持ち込むと**相手エージェントが自動レビュー**（ユーザー持ち込みは両エージェント。ダイアログでOFF可、
  フォルダ投入は自動レビューなし＝ボタンで依頼）
- レビューはファイル内容（大きい場合はパス参照）に対して行われ、
  末尾の「【判定】承認 / 条件付き承認 / 差し戻し」をチップ表示
- レビューはスレッドとは別の使い捨てセッションで実行（スレッド文脈を汚さず、並列実行も安全）
- 最終判断はユーザー（承認 / 差し戻しボタン）。再レビュー依頼も各エージェントに個別に可能
- プレビュー: Markdown はレンダリング、コード/テキストは等幅表示、画像はインライン表示
- 削除はファイルを `pool/.trash/` へ退避（復元可能）

## 外部セッション同期

各スレッドの実体は通常の CLI セッションなので、デスクトップ版 Claude Code や
ターミナル（`claude --resume <id>` / `codex resume <id>`）で同じスレッドを続けられる。
外部でやり取りした分はセッション記録ファイルの増分から検出し、
「外部セッションから同期」ラベル（破線枠）でスレッドに取り込まれる。

- チェックは 30 秒ごと＋各自動応答の直前
- 同期されたメッセージは自動応答のトリガーにはならない（外で完結した会話に二重返答しない）

## データ

- `u2a2a/data/state.json` に自動保存（git 管理外）。
- 複数ウィンドウで開いても SSE でライブ同期。
